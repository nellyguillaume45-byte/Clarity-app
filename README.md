# Clarity-app

Prototype V0 de **Clarity** — *Comprendre. Clarifier. Avancer.*

Cette première version valide le moteur interactif du parcours **🧭 La Boussole du choix** : réponses réelles, choix, priorités, distinction faits/anticipations, prochain pas, synthèse et suivi dans **Mon parcours**.

## Publication GitHub Pages

Dans le dépôt : **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**.

Le site sera ensuite disponible à l’adresse :

`https://nellyguillaume45-byte.github.io/Clarity-app/`

## Données

La V0 fonctionne sans backend et sans IA payante. Les réponses sont enregistrées uniquement dans le stockage local du navigateur (`localStorage`) de l’appareil utilisé.
